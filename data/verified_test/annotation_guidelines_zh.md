## 1. 这个项目在做什么,为什么需要你

我们在让计算机读唐代墓志,自动找出墓志里提到的墓主亲属,并判断每个人是墓主的什么人(父亲、祖父、岳父、女婿……),最后把上万篇墓志的亲属关系连成一张唐代人物网络。

计算机的"老师"是历史学者整理的人物库(CBDB)。但我们发现这份人物库本身**漏了一些人、也有记错的地方**,而计算机的输出又没人检查过。所以现在需要人对照墓志原文,逐条判断:**这个人是不是真的在原文里?他与墓主的关系是不是表里写的那样?**

你判断的依据**只有墓志原文**。v3 表已去掉模型的判断结果,只留原文片段;黄色列是要填的,可以下拉选择。

## 2. 墓志长什么样

一篇唐代墓志通常几百字,结构很固定,亲属信息集中在几处:

```
唐故朝散大夫胡府君墓志铭并序                      ← 标题:墓主的官职和姓
君讳永,字敬延,安定临泾人也。                      ← 墓主的名、字、籍贯
祖亮,夏中书侍郎……父邕,魏开府、祭酒……            ← 祖先:通常依次写曾祖、祖、父
……(生平、官历、品德)……
夫人清河张氏,东海太守势之女也。                    ← 配偶,以及配偶的父亲
有子质,任丰州司法参军事……                         ← 子女
以某年某月某日终于某里之私第,春秋八十有八。          ← 卒年、年龄
……铭曰:……                                        ← 铭文(韵文,一般没有亲属信息)
伯祖国珍,后魏司徒安定公。兄长粲,陇东王。            ← 有时文末还会补记亲属
```

几个阅读习惯:
- **墓志常常只写名,不写姓。**"祖亮""父邕""有子质",他们的姓都是胡,与墓主同姓。表里的"胡亮""胡邕"是我们按家族补上的姓。
- **"讳"后面是名。**"君讳永""祖讳亮"。"讳"本身不是名字的一部分。
- **女性常常没有名,只有"某氏"。**"夫人张氏"。表里会直接用"张氏"当名字。
- **"X 之女""X 之孙"是倒着说的。**"夫人张氏,势之女也"——"势"是夫人的父亲,所以是墓主的岳父。"白水公至仁之曾孙"——墓主是至仁的曾孙,所以至仁是墓主的曾祖。
- **女性墓主的墓志**(标题常作"某府君夫人某氏墓志")会写两家人:先写她本家的祖、父,再写"归于某氏"(嫁给谁),之后出现的祖、父往往是夫家的。

## 3. 关系码:怎么读、怎么写

### 3.1 八个字母

| 字母 | 含义 | 字母 | 含义 |
|---|---|---|---|
| **F** | 父 | **M** | 母 |
| **S** | 子 | **D** | 女 |
| **H** | 夫 | **W** | 妻 |
| **B** | 兄弟 | **Z** | 姊妹 |

### 3.2 读法:从墓主出发,一步一步走

关系码是一串字母,**从左往右读,每个字母走一步,起点永远是墓主**。

- `F` = 墓主的父
- `FF` = 墓主的父的父 = 祖父
- `FFF` = 曾祖父;`FFFF` = 高祖父
- `WF` = 墓主的妻的父 = 岳父
- `DH` = 墓主的女的夫 = 女婿
- `SS` = 子的子 = 孙;`SD` = 孙女;`SSS` = 曾孙
- `BS` = 兄弟的子 = 侄;`ZS` = 姊妹的子 = 外甥
- `FB` = 父的兄弟 = 伯父或叔父;`FZ` = 姑
- `MF` = 母的父 = 外祖父;`MB` = 舅
- `HF` = 夫的父 = 公公;`HFF` = 夫的祖父
- `SW` = 子的妻 = 儿媳;`SWF` = 儿媳的父 = 亲家

写的时候**不区分长幼**:兄和弟都是 B,姊和妹都是 Z,长子次子都是 S,伯父叔父都是 FB。

### 3.3 常见称谓对照表

| 原文称谓 | 关系码 | 原文称谓 | 关系码 |
|---|---|---|---|
| 父、考、皇考、先考、烈考、显考 | F | 母、妣、先妣、皇妣、太夫人 | M |
| 祖、祖父、王父、大父、皇祖 | FF | 祖母、王母 | FM |
| 曾祖、曾王父、大王父 | FFF | 高祖 | FFFF |
| 五代祖 | FFFFF | 外祖、外王父 | MF |
| 子、嗣子、长子、次子、季子、少子、孤子、哀子、嗣 | S | 女、长女、次女 | D |
| 孙、长孙、嫡孙 | SS | 曾孙 | SSS |
| 兄、弟、长兄、仲兄、季弟 | B | 姊、妹、女兄、女弟 | Z |
| 伯父、叔父、季父、从父 | FB | 姑 | FZ |
| 舅(墓主为男性时) | MB | 姨 | MZ |
| 从父兄、从兄、从弟、堂兄 | FBS | 从祖 | FFB |
| 侄、姪、从子、犹子 | BS | 甥、外甥 | ZS |
| 妻、夫人、继室、前夫人 | W | 夫、君子(女性墓主的丈夫) | H |
| 婿、女婿、子婿 | DH | 妇、子妇 | SW |
| 外舅、岳父 | WF | 外姑 | WM |
| 舅、君舅(女性墓主语境) | HF | 姑(女性墓主语境) | HM |
| 内兄、内弟 | WB | 姊夫、妹夫 | ZH |

注意最后两行:同一个字在男性墓主和女性墓主的墓志里意思不同。"舅"对男墓主是母亲的兄弟(MB),对女墓主则是丈夫的父亲(HF);"姑"同理。

### 3.4 女性墓主的特别规则

女性墓主的墓志里,亲属分本家和夫家,关系码必须区分:

| 原文 | 指谁 | 关系码 |
|---|---|---|
| 开头"夫人X氏……曾祖A,祖B,父C" | 本家 | FFF、FF、F |
| "归于Y氏某"(嫁给谁) | 丈夫 | H |
| 嫁人之后出现的"曾祖、祖、父",或与丈夫官职并列的祖先 | 夫家 | HFFF、HFF、HF |
| "有子某" | 她的儿子 | S(不是 HS) |

怎么分本家和夫家:看位置和上下文。通常"归于某氏"之前写的是本家,之后写的是夫家;夫家的祖先常和丈夫的姓一致。

### 3.5 容易混淆的几种写法

| 写法 | 怎么理解 | 关系码 |
|---|---|---|
| "夫人张氏,势之女也" | 势是夫人的父亲 | 张势 = WF |
| "母王氏,某之女" | 某是母亲的父亲 | MF |
| "白水公至仁之曾孙" | 墓主是至仁的曾孙 | 至仁 = FFF |
| "盐山县尉知诲之子" | 墓主是知诲的儿子 | 知诲 = F |
| "长女适河东柳岘"/"长女河东柳氏名岘" | 岘是女儿的丈夫 | 柳岘 = DH |
| "有子三人:长曰溥,次曰涣,季曰鸿" | 三个儿子 | 各为 S |
| "伯祖国珍" | 祖父的兄弟 | FFB |
| "从父弟某" | 父亲兄弟的儿子 | FBS |
| "外孙某" | 女儿的儿子 | DS |

## 4. 判"对"的两个条件

一行要填"对",必须**同时**满足:

**条件一:这个人确实在原文中出现。**
- 只出现名、没出现姓 → 算出现(姓是我们补的)
- 名字多一个字或少一个字(表里"胡长粲",原文"兄长粲",名应是"粲"或"长粲"都可接受;但表里"胡粲"而原文"长粲"要看是否同一人)→ 人对但名字不准,填"名字有误"
- 把官职、地名、谥号、撰文人、书丹人当成了亲属 → "无此人"
- 原文里根本没有这个人 → "无此人"

**条件二:关系码与原文称谓完全一致。**
- 辈分要对:原文"祖",关系码必须是 FF,写成 F 或 FFF 都是错
- 父系母系要对:"外祖"是 MF,不是 FF
- 本家夫家要对(女性墓主):夫家祖父是 HFF,不是 FF
- 人对关系错 → 填"错",并在"更正关系码"里填正确的

## 5. 四个工作过的例子

**例 1**
> 原文片段:……曾祖【卿】,隋任怀州武德县令……
> 候选:赵卿 | FFF(曾祖父)

"曾祖卿"→ 曾祖 = FFF,人在原文里。**结论:对。**

**例 2**
> 原文片段:……祖【安】,周任雍州华阴县令……
> 候选:杨安 | F(父亲)

原文说"祖",是祖父,关系码应为 FF。**结论:错,更正关系码 FF。**

**例 3**
> 原文片段:……御史里行李躔【撰】公讳师正,字中权……
> 候选:王撰 | S(儿子)

"撰"是"撰写"的意思,"李躔"是撰文的人,不是墓主的儿子。**结论:无此人。**

**例 4**(女性墓主张氏)
> 原文片段:……程君曾祖照,齐任州录事参军。祖【政】,隋任并州太原县令……
> 候选:张政 | FF(祖父)

这是女性墓主,"程君"是她丈夫,"曾祖照、祖政"都是丈夫家的人,所以政是夫之祖父 = HFF。另外他姓程不姓张。**结论:错,更正关系码 HFF,备注"姓应为程"。**

## 6. 操作步骤

1. 打开 Excel,先看"说明"工作表,再从"1_测试集候选"开始。
2. 每一行:先读"关系释义"(关系码的中文翻译),再看"原文片段"(候选人名用【】标出,前后各 45 字)。
3. 片段不够判断时(比如要确认是本家还是夫家),到"0_测试集原文"按"文档"编号找全文。
4. 在最后三列填写:
   - **核对结论**:只能填 `对` / `错` / `无此人` / `名字有误` 四种之一
   - **更正关系码**:结论是"错"时填正确的关系码;其他情况留空
   - **备注**:不确定、原文残缺、两可的情况都写在这里;"名字有误"时写正确的名字
5. 不要改动其他任何列,不要删行、排序。
6. 通读某篇全文时,若发现一位亲属是表里所有行都没列出的,在表 1 末尾新增一行:填文档、墓主、人名、关系码,来源填"人工新增",核对结论填"对"。

## 8. 反馈方式

1. 在 Excel 里直接填,文件改名为 `人工校验表_v1_已填_姓名.xlsx` 发回。
2. 多人分工时按"文档"列切分,每人负责一段文档编号,不要两人填同一行。
3. 结论用词固定,不要写"应该对""可能错";拿不准就填最接近的结论,把疑问写在备注。
4. 收到后由程序自动汇总:计算每个系统(包括人工库本身)的真实准确率、裁决模型的可靠度、可信度等级的真实正确率,并把更正合并进数据集的新版本。

## 9. 常见问题

| 情况 | 怎么处理 |
|---|---|
| 原文残缺(□)导致名字不全 | 名字有误 + 备注"原文残缺" |
| 同一个人出现两行、关系码不同 | 分别判,通常只有一行对 |
| 候选人名只有一个字,原文也只有一个字 | 算对,不要因为没有姓判错 |
| 原文说"长子""嗣子",关系码写 S | 对(不区分长幼) |
| 原文说"伯父",关系码写 FB | 对(伯叔不分) |
| 候选是"张氏"这种只有姓的 | 看原文是否确有这位"张氏"及其关系 |
| 一个人在原文里既是"夫人"又提到"X 之女" | 夫人 = W;X = WF;各自一行 |
| 原文自相矛盾 | 按最合理的读法判,备注说明 |
| 实在无法判断 | 填最接近的结论,备注"不确定" |
